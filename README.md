# DBMS

### Project Overview

This repository contains the Week 1 deliverables for the **E-Commerce Order Management Database System**. The objective of this phase is to analyze the business requirements of an online shopping platform and prepare a Software Requirement Specification (SRS) document that serves as the foundation for the database design.

### Objectives

* Analyze the business scenario.
* Identify the business requirements.
* Explain the purpose of each core entity.
* Identify stakeholders and business processes.
* Define functional and non-functional requirements.
* Define the project scope.
* Identify assumptions and constraints.
* Prepare the Software Requirement Specification (SRS).

### Core Entities

The project uses the following mandatory entities:

* Customer
* Category
* Product
* Supplier
* Order
* Order Details
* Payment
* Shipment
* Review
